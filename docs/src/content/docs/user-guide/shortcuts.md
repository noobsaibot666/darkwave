---
title: Shortcuts
description: Keyboard-led auditioning and organization shortcuts.
---

Initial shortcut targets:

- Space: play or pause.
- Arrow Up / Arrow Down: previous or next sound.
- Shift selection: extend a range from the anchor row.
- Command/Control selection: add or remove rows without losing the existing selection.
- Arrow Left / Arrow Right (while the seek bar has focus): nudge playback 5 seconds back or forward; hold Shift for a larger 15-second step.
- F: toggle favorite.
- L: toggle loop.
- Command/Control K: command palette.
- Command/Control I: import.
- Command/Control E: export selected.
- Command/Control Shift C: copy the selected sound's file path.
- Command/Control F: focus search.
- Escape: close transient panels.

Shortcuts must remain available without requiring pointer interaction.

"Focus Search" doesn't search anything by itself — it moves keyboard focus into the search box (scrolling it into view first if needed) and selects any text already there, so typing immediately replaces it. The actual search runs as you type, the same as clicking into the box directly.

The command palette exposes import, search, tagging, collection assignment, export, reveal, conversion, rescan, settings, and maintenance actions.

Undo (`Cmd/Ctrl+Z`) and Redo (`Cmd/Ctrl+Shift+Z`) are native menu items under Edit rather than toolbar buttons — the accelerator works the same either way, and Cut/Copy/Paste/Select All live in the same menu for normal text-field editing. The full shortcut list is also available any time via Help → Keyboard Shortcuts (`Cmd/Ctrl+/`).
